# HMS Backend (Starter)
## Quick start
1. Copy `.env.example` to `.env` and fill MONGO_URI and JWT_SECRET.
2. Install dependencies:
   ```
   cd backend
   npm install
   ```
3. Start:
   ```
   npm run dev
   ```
The API will be at http://localhost:5000
Endpoints: /api/auth, /api/entry, /api/complaints, /api/notices
